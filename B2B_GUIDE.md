# Мелкий опт SpinPoint

Открыть B2B-раздел: https://dimarger.github.io/spinpoint/#/wholesale

## Покупателю

На странице сотрудничества выберите модель, вариант и количество, затем добавьте следующую позицию. Заявка включает весь текущий кошик; количество и варианты можно изменить в корзине. В корзине переключатель «Малий опт» включает индивидуальные цены, отключение возвращает розничный расчёт.

Порог считается по ID модели: например, две чёрные и три красные накладки одной модели дают 5 штук. Разные модели не складываются для порога. До 3 штук действует розница. Выбирается самый большой достигнутый порог 3 / 5 / 10. Если цена именно этого порога не задана, показывается «Ціна за запитом», без подстановки соседней цены, розницы или нуля. При неизвестных ценах полная сумма и стоимость сборки не выдаются за известные; отдельно указывается только известная часть стоимости товаров.

Контактная форма подготавливает сообщение с товарами, вариантами, количеством, статусами, сроками, ценами и контактом покупателя. Telegram открывает черновик для @maybewritee; посетитель отправляет его сам. Формирование и отправка заявки не подтверждают заказ. Viber по-прежнему временно отключён.

## Владельцу

Редактор: /#/catalog-editor. Для каждой модели доступны розничная цена, «Опт від 3 / 5 / 10 шт.» за одну единицу, статус и строк поставки. Пустое поле оптовой цены означает запрос менеджеру. Ноль, отрицательные, нечисловые цены и значения с точностью больше копейки не принимаются. Автоматических скидок нет; даже более низкая цена соседнего порога не выводится автоматически.

Оптовые цены всех 80 моделей оставлены незаполненными: проверенной полной себестоимости нет, поэтому безопасную числовую цену назначить нельзя. Перед заполнением собственник отдельно проверяет закупку, международную доставку, комиссии, упаковку, налоги и прочие расходы. Розничный прайс сохранён без изменений. Прибыль не рассчитывается и не гарантируется.

Статусы: «В наявності», «Під замовлення», «Тимчасово недоступний». Исходный каталог сохранил 79 товаров под заказ и один временно недоступный; подтверждённых складских остатков не добавлялось. Статус «В наявності» ставьте только после подтверждения остатка. Для предзаказа базовый ориентир — 20–30 дней; окончательный срок согласовывается перед оплатой, редактор позволяет указать другой согласованный ориентир.

«Застосувати локально» сохраняет изменения только в текущем браузере. Для всех покупателей: экспортируйте JSON, замените src/data/products.json и опубликуйте проверенную сборку через существующий workflow. Это статический сайт, редактор не является защищённой серверной админпанелью. Проверка и экспорт удаляют неизвестные поля: закупку, поставщиков и приватные сведения в каталог не добавляйте.

Новая публичная структура: wholesalePrices с ключами «3», «5», «10» и значениями число / null; отсутствие ключа также означает запрос. Старые JSON без wholesalePrices принимаются как пустые тарифы. Отсутствующий leadTime получает «20–30 днів». В схеме сохранены прежние ID статусов preorder / available / unavailable. Хранилище spinpoint-shop-v1 мигрирует на версию 3 без очистки корзины, вариантов, обранного или темы. Правки розничных цен из версии 2 сохраняются; прежняя миграция версии 1 на актуальный розничный прайс продолжает работать. Общий режим опта также сохраняется.

## Внутренняя себестоимость в будущем

Для будущего закрытого учёта предусмотрено отдельное хранилище, связанное с каталогом по productId, за пределами public JSON и клиентского состояния. План — в SUPABASE.md. Сейчас приватной базы и расчёта прибыли на сайте нет; все внутренние суммы остаются вне публичного проекта.
