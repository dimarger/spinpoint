# Зображення каталогу

Каталог використовує локальні WebP у `public/images/products/`. Кожен файл названий за публічним ID моделі. Прозорість зберігається в alpha-каналі; фону чи цінових плашок у файлах немає.

Фотографії відповідних товарних карток оброблено вбудованим ImageGen. Вихідні зображення, походження й приватний розрахунок закупки зберігаються окремо від публічного сайту. Обробка фону не підтверджує автентичність або якість фізичної партії. Права на комерційне використання фотографій потрібно погодити з їхніми власниками.

Основний запит для кожного зображення:

> Видалити фотографічний фон до справжньої прозорості. Зберегти сфотографований товар, упаковку, фізично надруковані назви моделі та логотипи, колір, пропорції й матеріали. Не вигадувати розпаковану накладку, якщо показана лише упаковка. Розмістити предмет повністю по центру з прозорими відступами. Не додавати текст, ціну, плашки або реквізит.

Для кадрів із зовнішніми написами додано: прибрати окремі позначення варіанта FL/CS та накладені на фото написи сайту; зберегти друк на самому товарі.

Фотографії упаковок навмисно залишені упаковками. Колір поверхні, жорсткість, товщина й рукоятка визначаються вибраним варіантом та описом. Кадр із кількома кольорами чохла не означає набір: у описі зазначена одна одиниця.
