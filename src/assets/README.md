# Медіа

Робочі локальні зображення знаходяться в `public/images/`. `hero.webp` — створена через вбудований ImageGen рекламна ілюстрація без назви конкретної моделі; оригінал оптимізовано у WebP. Ілюстрації категорій — власний SVG-компонент `ProductArt`, вони явно позначені.

Промпт ImageGen: «Photorealistic studio still life: one professional unbranded table tennis racket with textured black rubber, natural wood edge and walnut flared handle leaning diagonally, a white ball in foreground. Deep cobalt blue matte table, dark navy background, dramatic side lighting, premium sports editorial photography. Landscape 3:2, subject at right, no text, logos, watermark, people. Illustrative promotional racket, not a named product.»

Медіа конкретних моделей потрібно додати окремо з правом використання. Зовнішніх шрифтів, аналітики чи випадкових фото немає.
