# SpinPoint — GitHub Pages

Адрес сайта: https://dimarger.github.io/spinpoint/

Репозиторий: https://github.com/dimarger/spinpoint

Показ магазинам: публичная демонстрационная витрина с 80 товарами и прайсом владельца. Telegram: https://t.me/maybewritee. Viber временно отключён: ссылки не открываются, в форме показана неактивная кнопка с пояснением. Остальные условия продавца и обработка заказов остались в прежнем режиме согласования.

Публикация настроена через .github/workflows/deploy.yml: push в main запускает установку зависимостей, TypeScript, линтер, тесты, сборку и публикацию dist через GitHub Actions. HashRouter и относительный base поддерживают путь /spinpoint/. Приватные закупочные расчёты и папка sourcing-private находятся за пределами репозитория и не публикуются.

B2B-раздел: https://dimarger.github.io/spinpoint/#/wholesale. Оптовые цены заполняются владельцем отдельно для каждой модели, отсутствующие остаются «Ціна за запитом». Подробности управления — в B2B_GUIDE.md.

Управление контактами: src/config/site.ts. Для возврата Viber потребуется актуальный номер и viberEnabled: true. Текст Telegram формируется в браузере; сообщение отправляет сам посетитель после проверки адресата. Онлайн-оплата и автоматическое принятие заказа не добавлялись.
